# 法譯助手｜法律合約條款翻譯助手

這是一個供法律事務部律師審閱合約使用的前端 MVP 展示頁面，提供繁體中文企業法律風格介面與模擬互動流程。

## 啟動方式

本版本為純 HTML、CSS、JavaScript，不需要安裝依賴。直接以瀏覽器開啟 `index.html` 即可預覽。

也可以在專案根目錄執行任一靜態伺服器，例如：

```bash
python3 -m http.server 8000
```

接著開啟 `http://localhost:8000`。

## 主要功能

- 法律事務部工作總覽與翻譯統計
- PDF、DOC、DOCX、TXT 檔案選取與拖放展示
- 英文／繁體中文翻譯方向選擇
- 原文／譯文雙欄審閱工作區
- 法律語氣、定義詞與術語一致性提醒
- 公司法律術語辭典與即時搜尋
- 待審閱條款、審閱狀態與提醒確認
- 模擬儲存、匯出與翻譯處理回饋
- 響應式版面與基本鍵盤操作支援

## 注意事項

目前為前端展示／模擬資料版本，尚未整合真實文件解析、AI 翻譯 API、身分驗證、資料庫或文件匯出服務。正式上線前，應依企業資安政策加入權限控管、傳輸與儲存加密、保存期限、稽核紀錄及資料不作模型訓練等機制。

翻譯結果僅供律師審閱，不取代法律專業判斷。
