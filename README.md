# 法律條款翻譯與合約審閱助手（Issue #3）

本專案為可直接在現代瀏覽器開啟的前端 Web 應用，提供法律條款翻譯與合約審閱輔助流程。

## 安裝與啟動

本專案無需安裝套件，直接開啟以下檔案即可：

- `/home/runner/work/PJ1/PJ1/index.html`

也可在專案根目錄啟動靜態伺服器：

```bash
python3 -m http.server 8000
```

再開啟 `http://localhost:8000`。

## 功能說明

- 貼上或輸入原始合約條款
- 選擇原文與目標語言（至少含繁體中文、英文，並保留擴充結構）
- 以法律語境的 mock/demo 方式產生譯文
- 原文與譯文逐句對照顯示，便於審閱
- 顯示條款審閱提示（義務、權利、期限、付款、責任限制、終止、保密、準據法、爭議解決）
- 提供複製譯文、清除內容、空狀態、載入狀態與錯誤提示
- 支援鍵盤操作（`Ctrl/Cmd + Enter` 快速執行翻譯）與基本無障礙（label、ARIA、焦點樣式）

## Mock / Demo 限制

目前翻譯與審閱分析為前端 mock/demo：

- 使用關鍵詞與術語替換示範法律語氣，不代表真實法律結論
- 審閱提示為輔助性提醒，採保守措辭（例如「可能需要確認」）
- 未整合文件解析、後端儲存、身分驗證、真實 AI 翻譯 API

## 未來接入真實翻譯或 AI 服務注意事項

- 導入正式翻譯/LLM 服務前，應建立法律術語庫與版本控管機制
- 應補強個資與機密資料保護（傳輸加密、儲存加密、權限分級、稽核軌跡）
- 建議加入可追溯提示來源、人工覆核流程與風險分級策略
- 不應將工具輸出直接視為法律建議，需由合格法律專業人士最終確認

## 驗證方式

專案無既有自動化測試框架，可先進行下列最小驗證：

```bash
node --check /home/runner/work/PJ1/PJ1/script.js
```

並在瀏覽器手動驗證：

1. 貼上條款後執行翻譯，確認有載入狀態與結果輸出。
2. 檢查原文/譯文對照是否逐句呈現。
3. 檢查審閱提示是否出現保守措辭內容。
4. 驗證「複製譯文」與「清除內容」按鈕行為。

## 法律免責聲明

翻譯結果與審閱提示僅供輔助，不構成法律意見或法律建議；使用者應由合格法律專業人士依具體事實與法域進行最終確認。
